## What happened (established 2026-09-10)

- The bucket has **versioning enabled**, and the missing EDF keys have **no versions and no delete markers**:
  the files were never uploaded, not deleted later. `build_bids.py` converted each session locally, uploaded it
  with `aws s3 cp` (3 attempts, size-scaled timeout), and did not keep the local tree, so a failed upload left
  no copy behind. The recordings table was built from the local conversion output, which is why it lists them.
- The 31 sessions that have sidecars but no EDF are not in the recordings table. The most likely cause is that
  edfio could not parse the source EDF (`deidentify_and_copy_edf` returns an error and no EDF is written) while
  sidecars were still emitted. Confirm on the source drive; if the source file is unreadable, remove the orphan
  session directories rather than restore them.
- The manuscript keeps the cohort numbers of the built release (4,914 subjects with EDF sessions, 23,607
  signal-bearing segments, 212,186 h), reproducible from `output/s3_recordings.csv`, and no longer claims a
  per-session completeness check of the published tree.
